# 对话导出功能说明

本文档只记录对话导出的产品功能与用户可见行为，不涉及技术实现细节。

## 功能概览

对话导出用于将当前 AI 对话保存为本地文件。用户可以在支持的平台对话页点击导出按钮，选择导出范围、导出格式、更多导出信息和图片样式，然后下载导出结果。

当前已开启的平台：

- Gemini
- ChatGPT
- DeepSeek
- Kimi
- 豆包
- Claude

在页面中逐条勾选提问或回复，点击「全选」时加载完整历史。各平台的加载方式如下：

- Gemini：自动向上滚动，逐步加载出全部历史对话。对于内容较长的会话，自动加载可能需要一些时间。
- ChatGPT：逐段加载并采集虚拟列表中的对话。
- DeepSeek：从对话顶部逐段扫描虚拟列表，补齐历史消息。
- Kimi：自动滚动到对话顶部，确认历史对话已经完整加载后导出。
- 豆包：在对话虚拟列表中自动向上加载，收集完整历史后导出。
- Claude：逐屏读取虚拟列表中的消息，补齐历史后按原始顺序导出，并恢复原来的阅读位置。

普通对话页与平台提供的对话分享页使用相同的导出规则；分享落地页中没有可读取的对话内容时，不显示导出入口。

## 入口

在支持导出的对话页面，点击顶栏的「导出对话」进入消息勾选模式，点击回复下方的导出按钮会预选该回复。

如果当前页面不是可导出的对话页，或平台暂未支持导出，按钮不会显示。

可以在扩展设置面板的「导出与截图」标签页中，按平台开启或关闭导出功能（仅列出已支持导出的平台，默认全部开启）。开关切换即时生效。

## 导出弹窗（其他平台）

导出弹窗包含以下设置区：

- 导出范围
- 导出格式
- 更多导出信息
- 图片主题色
- 对话选择列表
- 导出操作按钮

弹窗可以通过取消按钮、关闭按钮、点击遮罩或按 `Esc` 关闭。

## 导出范围（其他平台）

支持两种范围：

- 整个会话：导出自动加载后得到的全部对话节点。
- 选择对话：用户手动选择要导出的对话节点，导出时保持原始对话顺序。

打开弹窗后，扩展会先自动加载完整对话，因此对话选择列表会尽量列出会话中的全部对话节点。

选择对话时，列表中会显示每条对话的序号、用户内容预览和助手内容预览。用户可以逐条勾选，也可以使用“全选”一次选择全部对话。

如果没有选择任何对话，导出按钮不可用，并会提示至少选择 1 条对话。

## 导出格式

消息选择操作区还提供「复制内容」。Markdown、TXT、JSON、CSV
复制当前格式的文本；PNG 显示“复制图片”；PDF 保留“下载文件”。复制沿用当前
选择和信息开关，成功或失败后均保留操作区与选择，方便继续调整或下载。

支持六种格式：

- Markdown：生成 `.md` 文件，适合阅读、归档和二次编辑。
- TXT：生成 `.txt` 文件，适合纯文本保存。
- JSON：生成 `.json` 文件，适合结构化保存和后续处理。
- CSV：生成 `.csv` 文件，每轮一行（序号 /（提问时间）/ Q / A / 图片），适合表格分析；含 UTF-8 BOM 便于 Excel 识别中文。
- PNG：生成 `.png` 图片，适合分享和视觉归档。
- PDF：文字排版方案。把对话渲染成 HTML 后调用浏览器打印，导出时会弹出“打印/另存为 PDF”对话框。文字可选中/搜索，中文用系统字体，公式经 MathJax 渲染为 SVG，浏览器自动分页。

默认格式为 Markdown。PNG 与 PDF 都会显示“图片主题色”选项（PDF 用作头部与 Q 标记的强调色）。

## 更多导出信息

导出结果可以附带额外信息。当前支持：

- 对话 URL：记录导出来源页面地址。
- 导出时间：记录导出发生的本地时间。
- 对话时间：在每条用户提问处显示该提问的发生时间。

这三项默认开启，用户可以在弹窗中关闭。

“对话时间”来源于扩展的提问时间记录（ChatTimeRecorder，需平台开启 chatTimes 功能且该提问在扩展生效后发送）。历史对话或未记录的提问不会显示时间，即使开关开启也不会输出。

不同格式的展示方式不同：

- Markdown/TXT 会将标题、来源和导出时间显示在文件顶部；对话时间显示在每条用户提问处。关闭对应开关后，相应项不再出现。
- JSON 会在 `metadata` 中记录会话标题、平台、导出范围、导出格式、对话条数和图片数量等信息；其中来源 URL 与导出时间是否写入，跟随“对话 URL”“导出时间”开关；开启“对话时间”后，每条 `user` 记录会附带 `time` 字段。
- PNG 会将标题、来源和导出时间展示在图片顶部区域；对话时间展示在每条用户提问气泡顶部。关闭对应开关后，相应项不再展示。

## 图片主题色

选择 PNG 格式时，会显示“图片主题色”设置。用户可以选择导出图片顶部区域的主题色。切换到 Markdown、TXT、JSON 等其他格式时，“图片主题色”设置会隐藏。

当前可选主题色包括：

- 黑色
- 蓝色
- 紫色
- Gemini

默认主题色会优先跟随当前平台的时间轴激活色设置；没有可用设置时使用默认主题色。

## 导出内容

每条导出的对话包含：

- 对话序号
- 用户内容
- 助手内容
- 相关图片信息

用户和助手内容会按原对话顺序成对输出。如果某条用户消息没有找到助手回复，会显示“未找到回复内容”。

## 图片导出

导出会尽量保留对话中的图片信息，包括用户上传图片和助手回复中的图片。

Claude 同样支持用户上传图片、回复正文图片和点击放大的图片；响应式图片使用页面实际选中的图片地址。图片按地址去重，操作栏与小图标不会作为正文图片导出。

图片信息包含：

- 图片来源角色：用户或助手
- 图片尺寸
- 图片 alt 文本
- 图片地址

不同格式中的图片表现：

- Markdown：使用图片链接语法嵌入图片，并附带图片信息。
- TXT：以图片列表形式记录图片地址和图片信息。
- JSON：以结构化字段记录图片信息。
- PNG：尽量将图片直接绘制到导出图片中；如果图片无法内嵌，会显示“图片无法内嵌”的占位提示。

为避免误收集头像、图标等小装饰图，过小图片不会作为对话图片导出。

PNG 始终导出为一张完整长图。当对话过长、图片高度超出浏览器允许的画布上限时，会自动进行降级处理（例如适当压缩或截断超出部分），以保证文件仍可正常生成和下载。

## 富文本内容

导出会尽量保留助手回复中的可读内容。PNG 格式会尽量呈现更接近阅读视图的内容，包括：

- 段落
- 标题
- 列表
- 引用
- 代码块
- 链接文字
- 表格行列（PNG 与 PDF 均保留表头和单元格）
- 行内与独立数学公式

Claude 与 ChatGPT、Gemini 使用相同的富文本转换和公式解析能力。公式导出不依赖“公式复制”开关：Markdown/JSON 保留 LaTeX 与公式结构，TXT/CSV 保留可读源码，PNG 将公式绘制为图片，PDF 将公式渲染为矢量 SVG。渲染库无法加载时保留公式源码。

Markdown、TXT 和 JSON 以文本内容为主，会去除页面上的按钮、图标、辅助朗读标签、反馈按钮和来源列表等非正文内容。

## 文件命名

导出文件名使用会话标题生成。文件名会移除系统不允许出现在文件名中的字符，并限制长度，避免下载失败或文件名过长。

不同格式对应的扩展名：

- Markdown: `.md`
- TXT: `.txt`
- JSON: `.json`
- PNG: `.png`

## 状态提示

打开弹窗自动加载完整对话期间，会显示“加载对话中...”提示，并展示已加载的对话条数等进度信息。加载期间会暂时锁住对话选择和导出操作，用户可以取消加载；取消或加载完成后才能进行选择和导出。如果自动加载失败或被中断，会基于当前已加载到的对话节点继续，并尽量给出提示。

导出过程中会显示“导出中...”，并临时禁用导出按钮，避免重复触发。

导出完成后显示“对话已导出”。

导出失败时显示“导出失败”。

如果页面没有找到可导出的对话内容，会显示“未找到可导出的对话”。

## 当前限制

- 当前 Gemini、ChatGPT、DeepSeek、Kimi、豆包、Claude 已开启对话导出。
- 打开弹窗时会自动加载完整对话；需要滚动或虚拟列表加载的平台在对话很长时可能较慢，少数情况下也可能因页面限制无法加载到全部历史内容。
- ChatGPT 长对话中，未渲染轮次的图片可能无法收集（文本不受影响）。
- 图片可能因为来源限制、加载失败或浏览器安全限制无法内嵌到 PNG。
- 原始文件附件和 Artifacts 独立面板中的完整内容暂不作为文件打包；对话正文中可读取的内容按上述规则导出。
- PNG 为单张长图，超长对话会触发降级处理（压缩或截断超出部分）。
- 小尺寸装饰图不会作为对话图片导出。
- 导出内容以用户可读正文为主，不包含页面按钮、图标、反馈控件等界面元素。
